## Graphics Specifications

All layouts include realistic graphics features:

### PBR Materials
- Diffuse/Albedo maps (2048-4096px)
- Normal maps for surface detail
- Roughness maps for material properties
- Metallic maps for reflectivity
- Ambient Occlusion (where applicable)
- Subsurface Scattering (for skin/organic materials)

### LOD (Level of Detail) System
- LOD0: High detail for close viewing
- LOD1: Medium detail for mid-range
- LOD2: Low detail for far viewing
- LOD3: Minimal detail for distant objects

### Rendering Features
- Unity URP (Universal Render Pipeline)
- Real-time shadows
- Global illumination
- Screen space reflections
- Volumetric lighting
- Contact shadows
- Depth of field
- Bloom effects
- Motion blur (where applicable)

## Usage in Unity

### Loading Layouts
```csharp
// Example: Load a housing layout
string jsonPath = "Assets/Prefabs/Housing/Apartments/StudioApartment.json";
string jsonData = File.ReadAllText(jsonPath);
HousingLayout layout = JsonUtility.FromJson<HousingLayout>(jsonData);

// Create prefab from layout
GameObject prefab = CreatePrefabFromLayout(layout);
```

### Instantiating Prefabs
```csharp
// Example: Spawn a vehicle
VehicleLayout vehicleLayout = LoadLayout<VehicleLayout>("Vehicles/Cars/SportsCar.json");
GameObject vehicle = Instantiate(vehicleLayout.prefab);
VehicleController controller = vehicle.AddComponent<VehicleController>();
controller.Initialize(vehicleLayout.physics, vehicleLayout.specifications);
```

### Avatar Customization
```csharp
// Example: Customize avatar
AvatarBase avatar = LoadAvatar("Avatars/Base/MaleRealistic.json");
ApplyCustomization(avatar, "Avatars/Customization/HairStyles.json", "Long_Wavy");
ApplyCustomization(avatar, "Avatars/Customization/Eyes.json", "Blue");
ApplyAnimations(avatar, "Avatars/Animations/Locomotion.json");
```

## File Format Specifications

All layout files follow a consistent JSON structure:

```json
{
  "prefabName": "Category_Subcategory_Type",
  "category": "Housing|Vehicles|Avatars",
  "subCategory": "Specific category",
  "type": "Specific type",
  "metadata": {
    "nftCompatible": true,
    "ownershipType": "Individual",
    "economicTier": "Entry|Standard|Premium|Luxury|Ultra-Luxury"
  },
  "specifications": { ... },
  "graphics": {
    "lodLevels": 3-4,
    "polyCount": { ... },
    "textureResolution": { ... },
    "materials": [ ... ],
    "realisticFeatures": [ ... ]
  },
  "components": [ ... ],
  "price": {
    "purchasePrice": 0,
    "currency": "OMNI"
  }
}
```
